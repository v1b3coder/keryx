# Active plan — SDK + CLI + app protocol update

**Status: complete.** Source of truth: `spec/` (normative) and
`design/tooling.md` (SDK/CLI proposal).

## Deliverables

1. **SDK** (`sdk/`, Go module `github.com/v1b3coder/keryx/sdk`) — done
   - `keys` — Ed25519 keys, TUF keyids, role-tagged store, encrypted
     export/import bundles, `ErrMissingKey`
   - `repo` — Repo interface + DirRepo
   - `feed` — item types, OLPC sign/verify, image/attachment rules,
     private capability documents, tokens
   - `tufrepo` — build/load/verify the full TUF repo + anchor via go-tuf v2
   - `publisher` — Init, Publish, Unpublish, Channel/Author/Pattern/Company
     ceremonies, channel/root key rotation, RefreshTimestamp(+Expires),
     Validate(+Strict), Stage*/Apply
   - `ceremony` — stage/apply bundle (strict two-step), encrypted keys
   - `join` — payload/join URL encode/decode/validate + QR
   - `deploy` — Deployer (local, S3-compatible)
   - `config` — role-scoped workspace config
2. **CLI** `sdk/cmd/pub` — cobra, full spec/clients.md §2 surface
   (including the `rotate`/`revoke` and `channel mode --channel` spellings)
   plus the design/tooling.md §5 additions and `--stage`/`ceremony apply`.
3. **App** updated to the new protocol: per-item TUF targets, authors role,
   OLPC item signing, new private-feed document, no `_sig`/JSON Feed/JCS.
4. **Demo** generated by the SDK: `demo-tool` is a thin site-chrome wrapper
   over the SDK; `sdk/cmd/demo` generates a standalone SDK artifact;
   `../keryx-demo` regenerated and committed.
