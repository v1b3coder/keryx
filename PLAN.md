# Active plan — SDK + CLI + app protocol update

Source of truth: `spec/` (normative) and `design/tooling.md` (SDK/CLI proposal).

## Deliverables

1. **SDK** (`sdk/`, Go module `github.com/v1b3coder/keryx/sdk`)
   - `keys` — Ed25519 keys, TUF keyid, role-tagged file store, export/import, ErrMissingKey
   - `repo` — Repo interface + DirRepo
   - `feed` — item types, OLPC sign/verify, attachments, private capability documents
   - `tufrepo` — build/verify the full TUF repo + anchor via go-tuf v2
   - `publisher` — Init, Publish, Unpublish, ChannelAdd/Remove/Mode/Set, AuthorAdd/Revoke,
     PatternAdd/Remove, CompanySet, RotateChannelKey/Root, RefreshTimestamp, Validate
   - `join` — payload/join URL encode/decode + validation
   - `deploy` — Deployer (local, s3)
   - `config` — role-scoped workspace config
2. **CLI** `sdk/cmd/pub` — cobra commands covering the spec/clients.md §2 surface.
3. **App** updated to the new protocol: per-item TUF targets, authors role,
   OLPC item signing, new private-feed document, no `_sig`/JSON Feed/JCS.
4. **Demo** regenerated by the SDK CLI; app protocol tests pass against it.

## Verification

- `cd sdk && go test ./...`
- `cd sdk && go build ./...`
- `go run ./cmd/pub init ... && pub channel add ... && pub publish ... && pub validate`
- `cd app && npm test` (tests against `../demo` produced by the SDK)
